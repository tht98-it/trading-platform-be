# 📄 Product Requirements Document (PRD)

## 🎯 Mục tiêu

Xây dựng nền tảng theo dõi đầu tư mô phỏng tài sản như crypto/stocks, có giao dịch giả lập realtime và tương tác xã hội đơn giản.

## 🎯 Tính năng cốt lõi

- Đăng nhập Google
- Xem portfolio realtime
- Đặt lệnh mua/bán (market)
- Feed hoạt động realtime
- Biểu đồ giá tài sản
- Xem lịch sử lệnh

## ❌ Ngoài phạm vi MVP

- Limit order thực tế
- Kết nối sàn thật (Binance, Alpaca...)
- Xử lý tiền thật
- Tương tác xã hội (like/comment)

## 📝 Ghi chú phát triển

- Sử dụng mock data cho giá tài sản trong MVP, kế hoạch tích hợp API thật (như Binance) ở phase sau.
- Giao diện responsive với biểu đồ giá sử dụng TailwindCSS.
